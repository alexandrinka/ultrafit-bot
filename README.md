# Ultrafit Bot

Локальная Windows-программа для автоматической записи на групповые тренировки Ultrafit после открытия новой недели в понедельник в 00:00 по времени `Asia/Yekaterinburg`.

## Обычный запуск

1. Установить Java 17 или новее.
2. Запустить `run-ultrafit.bat`.
3. Если файла `ultrafit-secrets.bat` нет, скрипт запросит логин и пароль. Пароль при вводе не отображается.
4. Программа войдёт в Ultrafit и загрузит актуальные названия тренировок.
5. Выбрать `Запланировать на 00:00` или `Запустить сейчас`.

Расписание сохраняется только на компьютере в `ultrafit-config.json`.

## Сохранение логина и пароля

Чтобы не вводить данные при каждом запуске:

1. Скопировать `ultrafit-secrets.example.bat`.
2. Назвать копию `ultrafit-secrets.bat`.
3. Заполнить `ULTRAFIT_LOGIN` и `ULTRAFIT_PASSWORD`.

`ultrafit-secrets.bat` и `ultrafit-config.json` исключены из Git и никогда не должны загружаться на GitHub.

## Обновление программы

Нажать `Обновить программу` в основном окне. Программа:

1. проверит последний GitHub Release;
2. скачает `ultrafitBot.jar` и его SHA-256;
3. проверит целостность файла;
4. закроется, заменит JAR и запустится снова.

Личный файл настроек и файл с логином и паролем при обновлении не изменяются.

## Сборка

Из корня репозитория:

```bash
mvn --file ultrafitBot/pom.xml clean verify
```

Готовый файл: `ultrafitBot/target/ultrafitBot.jar`.

## Публикация новой версии

После отправки изменений в ветку `main` создать и отправить тег с номером версии:

```bash
git tag v1.0.1
git push origin v1.0.1
```

GitHub Actions автоматически проверит проект, соберёт JAR, создаст контрольную сумму и опубликует GitHub Release. Версия из тега будет записана внутрь JAR. Сборка также автоматически получает адрес текущего GitHub-репозитория, поэтому вручную прописывать имя владельца в коде не требуется.

Для первой установки на другом компьютере используется файл `UltrafitBot-windows.zip` из GitHub Releases. Последующие версии устанавливаются кнопкой внутри программы.
